# XVI・搭 部署运行指南

## 环境要求

| 软件 | 版本 | 说明 |
|---|---|---|
| JDK | 21+ | 后端编译运行 |
| Maven | 3.9+ | 后端构建（建议配置阿里云镜像） |
| MySQL | 8.x | 数据库 |
| 微信开发者工具 | 最新稳定版 | 小程序前端开发调试 |

## 一、初始化数据库

用 MySQL 客户端（命令行 / Navicat）执行：

```sql
source db/schema.sql
```

脚本会自动创建 `xvda` 库与 5 张表（sys_user / cloth / outfit / outfit_item / calendar_checkin）。

## 二、配置并启动服务端

1. 复制配置模板：把 `server/src/main/resources/application-local.yml.example` 复制为同目录下的 `application-local.yml`（该文件不会提交 Git），填入：
   - MySQL 账号密码
   - 微信小程序 AppSecret（微信公众平台 → 开发管理 → 开发设置；留空则按开发模式运行，openid 固定为 `dev-mock-user`，便于本地联调）
2. 启动：

```bash
cd server
mvn spring-boot:run
```

3. 验证：浏览器访问 `http://localhost:8080/api/ping`，返回 `{"code":0,...}` 即成功。

> 上传的衣物图片默认存放在服务端运行目录的 `upload/` 下，通过 `http://localhost:8080/upload/文件名` 访问。

## 三、运行小程序前端

1. 用微信开发者工具「导入项目」打开 `miniprogram/` 目录
2. 在 `project.config.json` 中把 `appid` 换成自己的小程序 AppID
3. 「详情 → 本地设置」勾选 **不校验合法域名、web-view（TLS 版本）以及 HTTPS 证书**（本地 HTTP 联调必需）
4. 编译运行

### 真机预览注意事项

- 手机与电脑必须连同一个 WiFi
- 把 `miniprogram/app.js` 中 `globalData.baseUrl` 的 `localhost` 改成电脑局域网 IP（`ipconfig` 查看，如 `http://192.168.1.5:8080`）
- 服务端防火墙需放行 8080 端口

## 四、常见问题

| 问题 | 原因与解决 |
|---|---|
| 小程序请求全部失败 | 未勾选「不校验合法域名」；或服务端未启动 |
| 登录返回 40029 | AppSecret 错误或与 AppID 不匹配 |
| 图片上传后不显示 | 检查 `upload/` 目录权限；确认服务端静态资源映射生效 |
| 推荐功能提示降级 | 未配置和风天气 key，属正常降级，不影响其他功能 |
| 启动时报 "Port 8080 was already in use" | 8080 被占用（旧进程未退出），先结束占用进程；或改配置 `server.port` 换端口，同时同步修改小程序 `app.js` 里的 `baseUrl` |
| 启动时报数据库连接失败 | `application-local.yml` 未创建或密码错误；确认 MySQL 已启动且 `xvda` 库已建好 |
